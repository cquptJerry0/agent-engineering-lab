# Agent Engineering Lab

这个仓库用于建立完整、可迁移、可验证的 Agent 工程心智。

核心方法不是执行一套固定课表，而是维护稳定知识图，根据当前掌握状态动态生成下一次学习单元。

## 从这里开始

1. 阅读[学习总纲](docs/学习总纲.md)，理解完整知识边界和依赖关系。
2. 查看[学习进度](docs/学习进度.md)，确认当前状态、薄弱点和掌握证据。
3. 进入[动态课程](docs/课程/README.md)，根据进度生成或继续当前 CU。
4. 第一轨完成贯穿案例驱动的`推导式理解`。
5. 第二轨完成独立的`面试训练`。
6. 需要核对机制来源或前沿方向时查阅[资料索引](docs/资料索引.md)。

## 学习运行时

```text
稳定层
  学习总纲 + 面试题库 + 资料索引

动态状态
  学习进度 + 当前目标 + 最近薄弱点

生成视图
  当前 CU
    ├── 推导式理解
    └── 面试训练
```

`学习总纲`是唯一知识源。课程只是当前学习状态下的临时编译结果，不能反向锁死固定课数和永久顺序。

## 双轨学习

第一轨负责理解：

```text
一个贯穿案例
  ↓
已有能力
  ↓
暴露问题
  ↓
引入机制
  ↓
系统继续演进
```

第二轨负责表达：

```text
完整题目
  ↓
核心判断
  ↓
30 秒回答
  ↓
完整回答
  ↓
连续追问
  ↓
真实证据
```

先完成第一轨，再生成第二轨。面试答案只能压缩已经稳定的理解，不能替代原理学习。
