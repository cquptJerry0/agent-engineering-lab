# 全栈秋招高 ROI 408 知识总纲

## 1. 知识边界

这套总纲回答：一个全栈工程师为了秋招和真实工程排障，应该怎样理解程序从数据结构、CPU、操作系统到网络请求的完整运行链。

包含：

1. 数据结构与算法。
2. 计算机组成原理。
3. 操作系统。
4. 计算机网络。
5. 与全栈请求链直接相关的 HTTP、TLS、缓存和并发扩展。

不包含：

1. 按院校划定的考研刷题进度。
2. 语言框架 API 清单。
3. 数据库和分布式存储的完整内核，后者归入存储体系总纲。

## 2. 总体运行模型

```text
输入数据
  └─ 由数据结构保存并维护不变量
       ↓ 算法选择决定时间与空间成本
CPU 执行指令
  └─ 缓存与内存层级决定真实访存代价
       ↓
操作系统提供进程、线程、虚拟内存和 I/O
  └─ 同步与调度决定并发正确性和延迟
       ↓
协议栈把字节跨主机传输
  └─ DNS、TCP、TLS、HTTP 决定请求语义和失败位置
```

## 4. 数据结构与算法

### 4.1 复杂度、数组、链表与哈希表

主知识点：

- 渐进复杂度、摊还分析与空间复杂度。
- 数组连续存储、缓存局部性和随机访问。
- 链表指针连接、插入删除和额外空间。
- 哈希函数、装载因子、冲突处理和扩容。

依赖与边界：

```text
数据规模
  └─ 决定复杂度是否成为瓶颈
连续布局
  └─ 改善局部性，但中间插入代价高
哈希映射
  └─ 平均常数查找，不提供稳定顺序和最坏界
```

掌握标准：面对用户去重、缓存索引和聚合任务，能根据访问模式选择结构并说明退化条件。

### 4.2 栈、队列、递归与状态机

主知识点：

- 栈的后进先出、调用栈和递归展开。
- 队列、双端队列和生产消费缓冲。
- 单调栈、单调队列的候选集不变量。
- 递归到显式状态机的转换。

掌握标准：能把 DFS、解析器、任务队列和撤销操作统一到“受限访问顺序”上解释。

### 4.3 树、堆与索引型数据结构

主知识点：

- 二叉树遍历与递归边界。
- 二叉搜索树的不变量和退化。
- 平衡树的高度控制与旋转。
- 堆与优先队列。
- Trie、并查集和索引型树结构。

依赖关系：

```text
有序关系
  ├─ 需要动态查找 → 二叉搜索树 / 平衡树
  ├─ 只关心最值 → 堆与优先队列
  ├─ 按前缀匹配 → Trie
  └─ 维护连通集合 → 并查集
```

掌握标准：能从不变量推导插入、删除和查询复杂度，并说明为什么堆不能替代有序索引。

### 4.4 图搜索、拓扑排序与依赖调度

主知识点：

- 图的邻接表与邻接矩阵。
- BFS、DFS 和访问状态。
- 拓扑排序、入度与环检测。
- 最短路径、最小生成树和并查集。

掌握标准：能把前端构建依赖、微服务调用和任务编排建模成图，并选择正确算法。

### 4.5 排序、二分与外部排序

主知识点：

- 比较排序下界、稳定性和原地性。
- 快排、归并、堆排的状态与退化。
- 二分查找的单调边界。
- Top K、分治和外部排序。

掌握标准：能写出边界正确的二分，并根据数据规模、稳定性和内存限制选择排序。

## 5. 计算机组成原理

### 5.1 数据表示、指令执行与函数调用

主知识点：

- 整数补码、浮点数误差、字节序和对齐。
- 指令周期、寄存器、栈帧和调用约定。
- 用户代码到机器指令的基本映射。

掌握标准：能解释溢出、精度、序列化字节序和一次函数调用的主要状态。

### 5.2 CPU 缓存、局部性与程序性能

主知识点：

- 缓存行、时间局部性和空间局部性。
- 多级缓存、缺失代价和预取。
- 写策略、缓存一致性和伪共享。
- 数组遍历、对象布局和数据导向设计。

掌握标准：能解释相同复杂度代码为何性能不同，并设计局部性对照实验。

### 5.3 流水线、中断、DMA 与 I/O

主知识点：

- 流水线吞吐和数据、控制冒险。
- 中断、异常和系统调用边界。
- 轮询、中断与 DMA 的控制权差异。

掌握标准：能解释 CPU 为什么不应逐字节搬运磁盘和网卡数据。

## 6. 操作系统

### 6.1 进程、线程、调度与上下文切换

主知识点：

- 进程地址空间和资源所有权。
- 线程执行上下文和共享状态。
- 就绪、运行、阻塞状态。
- 调度、时间片和上下文切换成本。

掌握标准：能解释异步不等于并行、线程多不一定更快，以及阻塞发生在哪里。

### 6.2 并发同步、死锁与内存可见性

主知识点：

- 原子操作与内存可见性。
- 互斥锁、信号量与条件变量。
- 临界区、竞态条件和 happens-before。
- 死锁条件与避免策略。

依赖关系：

```text
共享可变状态
  └─ 产生竞态
       ├─ 原子性问题 → 原子操作或互斥
       ├─ 顺序与可见性问题 → 内存同步
       ├─ 条件等待问题 → 条件变量
       └─ 多资源循环等待 → 死锁分析
```

掌握标准：能复现数据竞争和死锁，画出等待图，并说明锁解决与未解决的问题。

### 6.3 虚拟内存、页表、缺页与文件映射

主知识点：

- 虚拟地址、页表、TLB 和地址翻译。
- 缺页、换页、工作集与抖动。
- Copy-on-Write(写时复制)和 mmap(文件映射)。
- 堆、栈、共享库和内存映射区域。

掌握标准：能从一次地址访问追踪到物理页，并解释进程内存增长和缺页延迟。

### 6.4 系统调用、文件 I/O 与 I/O 多路复用

主知识点：

- 用户态、内核态和系统调用。
- 文件描述符、阻塞与非阻塞 I/O。
- select、poll、epoll 的事件管理模型。
- 零拷贝的边界和数据移动路径。

掌握标准：能解释高并发服务器为什么使用事件循环，以及 I/O 多路复用没有消除业务计算阻塞。

## 7. 计算机网络

### 7.1 分层、寻址、转发与 NAT

主知识点：

- 链路层、网络层、传输层和应用层职责。
- MAC、ARP、IP、子网、路由和 TTL。
- NAT、端口映射和连接跟踪。

掌握标准：能判断同网段、跨网段和公网访问时下一跳由谁决定。

### 7.2 TCP 可靠传输、流量控制与拥塞控制

主知识点：

- 三次握手、四次挥手和连接状态。
- 序列号、确认、重传和乱序重组。
- 接收窗口与流量控制。
- 拥塞窗口、慢启动和拥塞避免。
- TIME_WAIT、半连接和连接复用。

掌握标准：能区分丢包、对端处理慢和网络拥塞，并读懂一次 TCP 连接状态变化。

### 7.3 DNS、TLS、HTTP 与代理缓存链路

主知识点：

- DNS 递归解析与缓存层级。
- TCP 连接与 TLS 握手。
- HTTP 请求响应、方法、状态码和连接复用。
- Cache-Control、ETag、代理缓存与 CDN。
- HTTP/2 多路复用和 HTTP/3 over QUIC 的边界。

依赖关系：

```text
URL
  └─ DNS 得到地址
       └─ TCP 或 QUIC 建立传输
            └─ TLS 建立身份与密钥
                 └─ HTTP 交换语义消息
                      └─ 浏览器、代理和 CDN 执行缓存策略
```

掌握标准：能从浏览器 URL 追踪到响应渲染前，并根据证据定位 DNS、连接、TLS、服务端和缓存问题。

## 8. 完整依赖图

```text
复杂度
  ├─ 支撑 → 数组 / 链表 / 哈希
  ├─ 支撑 → 树 / 堆 / 图 / 排序
  └─ 进入工程 → 调度、索引和缓存

数据表示与局部性
  └─ 支撑 → CPU 缓存与真实性能
       └─ 进入操作系统 → 进程、虚拟内存和 I/O

进程与线程
  ├─ 共享状态 → 并发同步与死锁
  ├─ 地址访问 → 虚拟内存与缺页
  └─ 外部交互 → 系统调用与 I/O 多路复用

协议分层
  └─ IP 转发
       └─ TCP 可靠字节流
            └─ DNS / TLS / HTTP / 缓存组成全栈请求链
```

阅读顺序：先理解数据结构的不变量，再理解程序如何由 CPU 和操作系统执行，最后追踪请求如何跨网络完成。每个分支都可以动态形成 CU，但总纲顺序不等于固定课表。

## 9. 掌握标准

| 层级 | 证据 |
|---|---|
| 已理解 | 能独立画出机制链和关键不变量 |
| 已实验 | 能构造正常与失败输入，记录状态差异 |
| 已整合 | 能在全栈请求或项目中定位该机制的位置 |
| 已复核 | 换语言、框架或故障场景后仍能推导 |
