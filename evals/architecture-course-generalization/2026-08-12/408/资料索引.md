# 408 资料索引

## 证据规则

协议和操作系统机制以正式标准与官方文档为主；课程和教材只用于组织连续心智，不单独证明工程事实。

## 一级与二级来源

| 主题 | 来源 | 证据等级 | 用途 |
|---|---|---|---|
| TCP | [RFC 9293: Transmission Control Protocol](https://www.rfc-editor.org/rfc/rfc9293.html) | 正式标准 | 连接状态、序列号、确认与重传 |
| HTTP | [RFC 9110: HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110.html) | 正式标准 | 请求响应语义、方法与状态码 |
| HTTP 缓存 | [RFC 9111: HTTP Caching](https://www.rfc-editor.org/rfc/rfc9111.html) | 正式标准 | Cache-Control、验证与代理缓存 |
| TLS | [RFC 8446: TLS 1.3](https://www.rfc-editor.org/rfc/rfc8446.html) | 正式标准 | 握手、身份认证和密钥建立 |
| QUIC | [RFC 9000: QUIC](https://www.rfc-editor.org/rfc/rfc9000.html) | 正式标准 | HTTP/3 传输基础与多路流 |
| DNS | [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034.html)与[RFC 1035](https://www.rfc-editor.org/rfc/rfc1035.html) | 正式标准 | 域名空间、递归解析和报文 |
| Linux 调度 | [Linux Scheduler](https://docs.kernel.org/scheduler/index.html) | 官方文档 | 调度器和任务状态 |
| Linux 内存 | [Linux Memory Management](https://docs.kernel.org/mm/index.html) | 官方文档 | 页表、缺页和内存管理 |
| Linux 文件系统 | [Linux Filesystems](https://docs.kernel.org/filesystems/index.html) | 官方文档 | VFS、文件与 I/O 路径 |
| Java 内存模型 | [Java Language Specification Chapter 17](https://docs.oracle.com/javase/specs/jls/se25/html/jls-17.html) | 语言规范 | happens-before、可见性和同步 |
