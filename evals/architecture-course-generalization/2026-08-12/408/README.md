# 全栈秋招高 ROI 408 知识体系

## 使用顺序

1. 阅读[知识总纲](知识总纲.md)，建立完整边界和依赖图。
2. 查看[学习进度](学习进度.md)，确认当前状态和证据。
3. 需要核对机制时查阅[资料索引](资料索引.md)。
4. 本次随机生成的课程见[动态课程](课程/README.md)。

## 核心判断

本体系保留 408 的四个基础域，但按全栈工程师真实请求链重新组织：

```text
业务代码的数据组织
  ↓
CPU 与内存执行
  ↓
进程、线程和系统调用
  ↓
网络请求跨主机传输
```

知识总纲是唯一知识真相源。课程只根据学习进度和当前目标动态选课，不维护固定课表。
