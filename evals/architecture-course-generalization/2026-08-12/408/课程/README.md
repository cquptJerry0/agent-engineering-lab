# 408 动态双轨课程

## 课程合同

知识真相源是[学习总纲](../知识总纲.md)，动态学习状态来自[学习进度](../学习进度.md)。本次按[抽样记录](../../抽样记录.md)中的随机结果完成动态选课。

每个 CU 必须声明：

- 选课依据和覆盖知识点。
- 一个中心问题和贯穿案例。
- 从已有能力到暴露问题再到机制演进的推导链。
- 独立的推导式理解和面试训练。
- 状态写回条件。

生成文档不更新进度。完成实验、复述和复核后，下一 CU 再根据薄弱点动态决定并重新计算。
