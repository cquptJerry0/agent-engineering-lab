## 可复现算法

```python
import random

rng = random.Random(620082253)
selected = rng.sample(candidates_408, 2)
selected += rng.sample(candidates_storage, 2)
remaining = [item for item in candidates_408 + candidates_storage if item not in selected]
selected += rng.sample(remaining, 1)
rng.shuffle(selected)
```
