# 架构研究与双轨课程跨领域前向测试

## 测试目标

本目录验证两个 Skill 能否脱离 Agent 工程语境，处理全栈工程师秋招中的两个技术大块：

1. 秋招 ROI 最高的 408 内容。
2. 秋招 ROI 最高的存储体系原理。

测试分成两层：

```text
architecture-research
  产出完整知识边界、依赖、ROI 分层、掌握标准和资料索引
  ↓
course-delivery-orchestrator
  从候选 CU 池随机抽取 5 个主题，生成推导式理解与面试训练
```

## 用户画像与目标

| 项目 | 当前假设 |
|---|---|
| 用户角色 | 有前后端项目经验的全栈工程师 |
| 使用场景 | 2026 年秋招准备、工程排障、系统设计与面试表达 |

| 完成标准 | 能从请求、进程、内存、网络和存储状态推导机制，并完成实验与面试回答 |

## ROI 评分模型

“高 ROI”不是招聘平台给出的官方排名，而是本次研究使用的显式决策模型：

| 维度 | 权重 | 判断问题 |
|---|---:|---|
| 岗位覆盖度 | 30% | 前端、后端、全栈、基础架构岗位是否都会追问 |
| 前置杠杆 | 25% | 是否阻塞多个后续机制的理解 |
| 工程解释力 | 20% | 是否能解释真实性能、并发、网络或数据故障 |
| 面试深度 | 15% | 是否容易形成连续原理和项目追问 |
| 学习成本 | 10% | 是否能在有限时间形成可复述、可实验的闭环 |

分层含义：

```text
S：优先形成机制链和实验能力
A：在 S 层之后补齐，支撑系统设计和深入追问
B：保留在完整架构中，按岗位和薄弱点动态选择
```

## 能证明与不能证明

本次测试能够证明：

- 架构 Skill 可以在两个陌生技术大块上产出完整边界、依赖、ROI 分层、掌握标准和资料索引。
- 课程 Skill 可以从稳定总纲中随机选取主题，并根据请求时序、数据结构不变量、线程交错、落盘状态和复制偏移切换贯穿载体。
- 两个 Skill 的交接没有生成第二套知识树，CU 结论可以回到总纲。

本次测试不能证明：

- ROI 权重是所有公司和岗位的唯一最优答案。
- 课程正文已经被学习者真实掌握。
- 两个 Skill 对所有未知领域都必然一次成功。
