# 存储体系动态双轨课程

## 课程合同

知识真相源是[学习总纲](../知识总纲.md)，动态学习状态来自[学习进度](../学习进度.md)。本次根据[抽样记录](../../抽样记录.md)中的随机结果完成动态选课。

每个 CU 使用一个中心问题和贯穿案例，从数据状态、持久化边界或副本状态连续推导。推导式理解负责机制，面试训练负责可上场表达。

因果推导链统一遵循：

```text
已有能力
  → 暴露持久化或副本问题
  → 引入新机制
  → 观察数据状态变化
  → 注入故障并验证边界
```

生成课程不更新进度。完成正常与失败实验、独立复述和陌生案例复核后，才允许状态写回；下一 CU 根据新薄弱点动态决定并重新计算。
