# Agent 开发资料索引

## 1. 定位

这份文档统一管理稳定资料、证据等级、待验证方向和知识更新规则。

它不定义知识边界和学习顺序。知识范围以[学习总纲](学习总纲.md)为准，当前学习状态以[学习进度](学习进度.md)为准。

最后核对日期：`2026-08-10`。

## 2. 证据等级

| 等级 | 资料类型 | 可以证明什么 | 使用限制 |
|---|---|---|---|
| 一级 | 官方协议、正式规范、官方 API 文档、正式论文 | 真实契约、数据结构和原始结论 | 仍需核对版本与实验边界 |
| 二级 | 官方源码、RFC、架构文档、维护者文章 | 实现机制和工程取舍 | 单个项目不能自动代表通用最佳实践 |
| 三级 | 独立复现、Benchmark、工程复盘 | 效果、迁移性和失败条件 | 需要检查样本、指标和复现完整性 |
| 四级 | 系统课程、书籍、教程和专业博客 | 建立连续直觉和查漏补缺 | 不能单独定义知识主干 |
| 五级 | 演讲、播客、社交媒体和社区讨论 | 发现线索和争议 | 不直接写成事实 |
| 禁用 | 来源不明的泄漏代码和版本不明的反编译材料 | 最多提出待验证假设 | 不作为正式证据 |

## 3. 进入主干的门槛

一个新概念进入学习总纲前，至少需要：

1. 一个一级或二级来源确认机制真实存在。
2. 一个源码、最小实验、独立复现或真实请求证明它解决了可观察问题。
3. 能说明它与现有概念的真实差异，而不只是换了名称。
4. 能定义适用前提、失败边界和掌握证据。

## 6. 待验证方向

候选状态：

```text
线索 → 已核实 → 实验中 → 主干候选 → 已进入主干 / 已归档
```

| 方向 | 当前状态 | 当前处理 |
|---|---|---|
| Harness 自动优化 | 主干候选 | 继续验证独立评测、审批和回滚 |
| Agent 修改自身代码 | 实验中 | 只作为受控研究方向 |
| 模型权重自进化 | 实验中 | 保留在训练支线 |
| A2A 跨系统协作 | 主干候选 | 项目涉及跨系统 Agent 时深入 |
| GUI 与 Computer-use Agent | 已核实 | 项目需要真实界面操作时深入 |
| 长期自治后台 Agent | 已核实 | 继续验证租约、预算、告警和失控边界 |

## 7. 线索晋级

```text

  ↓

  ↓
判断进入待验证方向还是稳定主干
```

无法找到原始来源时，只记录为线索。

## 9. 更新节奏

- 模型 API、MCP、A2A 和主 Runtime 发生重要版本变化时立即核对。
- 每月扫描待验证方向是否出现新的官方证据或失败案例。
- 每季度检查主干是否出现重复概念、过期结论和失效实验。
- 新内容先更新证据卡片，再决定是否修改学习总纲。
