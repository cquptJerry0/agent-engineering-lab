# 面试题来源与证据

## 1. 使用原则

题库优先保留真实面试中的原始问法，再使用高频题库补全覆盖，最后依据官方资料增加当前工程机制必然产生的追问。

来源强度从高到低为：

1. 候选人描述的真实面试过程。
2. 多份面经归纳后的高频问题。
3. AI 公司公开的面试流程与样题。
4. 维护活跃的开源面试题库。
5. 根据官方协议、运行时和安全规范设计的机制题。

公开面经只能证明“有人这样问过”，不能证明所有公司都会问，也不能保证其中附带答案正确。

## 5. 官方机制依据

### S13：AI SDK UI

- 类型：官方前端 SDK 文档。
- 主要贡献：消息状态、工具调用 UI、流协议、生成式界面、自定义数据、错误处理和实时音频。
- 来源：
  - [AI SDK：Stream Protocols](https://ai-sdk.dev/docs/ai-sdk-ui/stream-protocol)
  - [AI SDK：Chatbot Tool Usage](https://ai-sdk.dev/docs/ai-sdk-ui/chatbot-tool-usage)

  - [AI SDK：UIMessage](https://ai-sdk.dev/docs/reference/ai-sdk-core/ui-message)

### S14：LangGraph 与 Agent 前端

- 类型：官方运行时文档。
- 主要贡献：Durable Execution(中断后可恢复的执行)、Checkpoint(执行检查点)、Interrupt(主动暂停)、人工审批、状态持久化和流式前端。
- 来源：
  - [LangGraph Overview](https://docs.langchain.com/oss/python/langgraph/overview)
  - [LangGraph Persistence](https://docs.langchain.com/oss/python/langgraph/persistence)
  - [LangGraph Interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts)
  - [LangChain Frontend Human-in-the-Loop](https://docs.langchain.com/oss/python/langchain/frontend/human-in-the-loop)

### S15：OWASP GenAI Security

- 类型：安全规范。
- 主要贡献：Prompt Injection(提示词注入)、输出处理、敏感信息、过度代理权、向量与 Embedding 风险。
- 来源：
  - [OWASP LLM Top 10](https://genai.owasp.org/llm-top-10/)
  - [OWASP Prompt Injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/)
  - [OWASP Agentic AI Threats and Mitigations](https://genai.owasp.org/resource/agentic-ai-threats-and-mitigations/)
