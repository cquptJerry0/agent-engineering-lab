# AI Agent 核心面试题

## 1. 使用边界

这份题库考察能否从模型交互原语出发，解释 Agent Loop(智能体执行循环)、工具、上下文、规划、运行时和持续改进，而不是背诵某个框架的接口。

## 2. 模型交互原语

### AGENT-MODEL-001：一次模型调用的输入、输出和停止条件分别是什么？

常见追问：

- system、user、assistant 和 tool 消息承担什么职责？
- finish reason(结束原因)为什么不能只判断有没有文本？
- 结构化输出、工具调用和普通文本如何统一进入执行循环？

主干定位：[模型交互原语](../学习总纲.md#52-模型交互原语)

来源：S1、S6、S8

### AGENT-MODEL-002：Temperature、Top-p 和上下文窗口如何影响 Agent 行为？

常见追问：

- 为什么降低随机性不等于获得确定性？
- 规划、工具参数生成和创意写作是否应该使用相同采样配置？
- 上下文接近上限时，成本、延迟和回答质量会怎样变化？

主干定位：[模型与表示基础](../学习总纲.md#51-模型与表示基础)

来源：S1、S6

### AGENT-MODEL-003：结构化输出和 Function Calling(模型生成结构化工具请求)有什么区别？

常见追问：

- 两者分别适合提取数据、路由决策和执行外部动作中的哪些场景？
- Schema(结构约束)校验失败后如何重试？
- 模型返回合法 JSON 是否就代表业务参数可信？

主干定位：[模型交互原语](../学习总纲.md#52-模型交互原语)

来源：S6、S8

### AGENT-MODEL-004：为什么 Agent 的可靠性不能只靠一段更长、更复杂的 Prompt？

常见追问：

- 哪些约束应放在代码、状态机、权限和校验器中？
- Prompt 适合表达什么，不适合保证什么？
- 如何通过实验判断问题来自 Prompt、模型能力还是系统设计？

主干定位：[Harness Engineering](../学习总纲.md#91-harness-engineering)

来源：S1、S6、S8
