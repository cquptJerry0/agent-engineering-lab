# AI Agent 面试题库

## 1. 定位

这个目录用于面试抽检和查漏补缺，不承担知识主干职责。

知识范围、概念定义和学习深度仍以[学习总纲](../学习总纲.md)为准。题库只负责回答：

1. 近期面试会从哪些角度提问。
2. 同一个知识点通常会怎样继续追问。
3. 当前学习体系还有哪些面试侧缺口。

题库暂时只收问题，不直接附答案。后续写答案时，应引用学习总纲中的主归属章节，避免在题库中重新建立一套知识定义。

## 3. 使用方式

每道题使用稳定编号，例如：

```text
FE-STREAM-001
AGENT-LOOP-001
RAG-RETRIEVAL-001
PROD-SYSTEM-001
```

建议按下面的方式复习：

```text
随机抽题
  ↓
先给一句核心判断
  ↓
画最小机制或调用链
  ↓
说明边界和失败
  ↓
给一个真实实现或实验
  ↓
接受连续追问
```

一题达到“可上场”至少需要：

- 不看资料说清它解决的问题。
- 能解释最小工作机制和关键数据流。
- 能给出一个失败场景以及定位方式。
- 能说明什么时候不应该使用该方案。
- 被追问实现细节时能够落到协议、状态、代码或评测证据。

## 4. 来源标签

| 标签 | 含义 |
|---|---|
| 真实面经 | 来源明确描述了真实面试过程或现场问题 |
| 高频题库 | 多份面经归纳或公开面试题库中的高频问题 |
| 机制补全 | 根据当前官方协议、运行时和安全规范补出的必备追问 |
| 用户样本 | 用户提供的截图、文字或实际面试记录 |

题目进入本目录不代表它属于第一轮学习主干。传统前端、数据库、限流算法和模型推理优化等内容可以保留为面试补充，但不能反向扩大[学习总纲](../学习总纲.md)的稳定主干。

## 5. 当前边界

- 收录前端偏 AI Agent、AI Agent 应用工程和相邻系统工程问题。
- 不收录纯模型训练算法的大规模题库，只保留与 Agent 应用选型直接相关的边界题。
- 不按具体 Agent 框架或前端开发套件的品牌组织题目。
- 同义题只保留一个主问题，常见变体作为追问合并。
- 原始来源样本允许保留重复，以便核对原始语境。

## 6. 后续维护

每次新增面经时先判断：

1. 这是一道新机制，还是旧问题的换皮问法？
2. 它应该进入哪个唯一主归属文档？
3. 它是稳定高频题，还是某家公司的一次性实现细节？
4. 当前学习总纲是否已经覆盖它？
5. 如果未覆盖，它应该进入主干、支线，还是只留在题库？
