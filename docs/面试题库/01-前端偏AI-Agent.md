# 前端偏 AI Agent 面试题

## 1. 使用边界

这份题库关注 AI 产品前端中特有的协议、状态、交互、安全和调试问题。传统 React、JavaScript 和浏览器题只在它们会直接影响 AI 交互链路时收录。

题目暂时不附答案。同义问法已经合并为追问，避免按照公司或框架重复建题。

## 2. 流式协议与增量渲染

### FE-STREAM-001：SSE 和 WebSocket 在 AI 流式回答中如何选择？

常见追问：

- 为什么大多数文本生成场景使用 SSE(服务端单向推送协议)，而实时语音或双向控制更适合 WebSocket(全双工连接协议)？
- 代理层缓冲、连接数限制、断线重连和心跳会怎样影响选择？
- 如果需要取消生成、重新生成和客户端回传状态，SSE 是否仍然够用？

主干定位：[模型交互原语](../学习总纲.md#52-模型交互原语)

来源：S1、S4、S5、S13

### FE-STREAM-002：模型返回的是 Token 流，前端为什么不能直接把每个分片当成一段文本渲染？

常见追问：

- 网络分片、UTF-8 字符、JSON 边界和模型 Token 边界为什么不是同一个概念？
- 如何处理半个 Markdown 标记、半个工具调用参数或半个多字节字符？
- 传输层、协议层和界面层分别应该负责什么？

主干定位：[模型交互原语](../学习总纲.md#52-模型交互原语)

来源：S1、S2、S13

### FE-STREAM-003：如何设计一套同时承载文本、推理状态、工具调用和自定义数据的流协议？

常见追问：

- 事件是否需要类型、消息编号、分片编号、关联调用编号和完成标记？
- 文本增量、结构化事件和错误事件如何避免混在一个字符串里？
