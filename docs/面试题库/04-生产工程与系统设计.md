# 生产工程与系统设计面试题

## 1. 使用边界

这份题库考察 Agent 从演示进入真实生产环境后，如何控制安全、状态、副作用、并发、成本和故障。系统设计题应说明容量假设、关键数据流、失败模式和验证方法。

## 2. 安全、权限与隔离

### PROD-SAFE-001：Prompt Injection(提示词注入)攻击如何防御？

常见追问：

- 直接注入和通过网页、文档、邮件进入的间接注入有什么差异？
- 指令与不可信数据如何隔离？
- 为什么只加一句“忽略恶意指令”不能成为安全边界？

主干定位：[可靠性、安全与治理](../学习总纲.md#111-可靠性安全与治理)

来源：S15、U1-9

### PROD-SAFE-002：工具调用的安全控制是怎么实现的？

常见追问：

- 工具白名单、参数 Schema、业务校验、用户权限和人工审批如何分层？
- 只读、可写、外发和不可逆操作如何分级？
- 模型生成的参数在什么位置被视为不可信输入？

主干定位：[可靠性、安全与治理](../学习总纲.md#111-可靠性安全与治理)

来源：S15、U1-10

### PROD-SAFE-003：Agent 的最小权限原则如何落到真实业务系统？

常见追问：

- 用户身份、Agent 身份和服务身份如何传递？
- 工具能否使用共享高权限账号？
- 临时授权、范围授权和审批后授权怎样设计？

主干定位：[可靠性、安全与治理](../学习总纲.md#111-可靠性安全与治理)

来源：S10、S15

### PROD-SAFE-004：Sandbox(受限执行环境)应该隔离哪些资源？

常见追问：

- 文件系统、网络、进程、环境变量、凭据和执行时间如何限制？
- 代码执行工具与普通 HTTP API 工具的隔离要求有什么不同？
- 沙箱逃逸或资源耗尽如何检测和止损？

- 第三方模型服务的数据保留策略如何进入系统设计？

主干定位：[可靠性、安全与治理](../学习总纲.md#111-可靠性安全与治理)
