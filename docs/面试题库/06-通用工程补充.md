# 通用工程补充面试题

## 1. 使用边界

这份题库保留 Agent 应用面试中常被顺带追问的限流、数据结构、数据库、批处理和基础调试问题。它们是面试补充，不反向扩大《学习总纲》的 Agent 主干。

## 2. 限流算法

### GENERAL-RATE-001：讲一下分布式令牌桶限流。

常见追问：

- Token Bucket(令牌桶)中的生成速率、桶容量和请求消耗如何定义？
- 多实例如何共享状态并保证原子扣减？
- Redis、Lua 脚本和本地预取令牌分别有什么取舍？

主干定位：[支线知识](../学习总纲.md#12-支线知识)

来源：U1-11

### GENERAL-RATE-002：漏桶算法是什么？

常见追问：

- Leaky Bucket(漏桶)如何把突发流量整形成稳定流量？
- 桶满时是拒绝还是排队？
- 它与消息队列和并发控制有什么关系？

主干定位：[支线知识](../学习总纲.md#12-支线知识)

来源：U1-12

### GENERAL-RATE-003：固定窗口、滑动日志和滑动窗口计数分别如何实现？

常见追问：

- 固定窗口为什么会在边界产生双倍突发？
- 滑动日志的精确性和存储成本如何权衡？
- Sliding Window Counter(滑动窗口计数)如何近似计算当前窗口请求量？

主干定位：[支线知识](../学习总纲.md#12-支线知识)

来源：U1-13

### GENERAL-RATE-004：滑动窗口和令牌桶相比有什么区别？

常见追问：

- 哪种算法允许短时突发？

- Agent 模型配额、工具调用和用户接口是否应该使用同一种限流？

主干定位：[支线知识](../学习总纲.md#12-支线知识)

来源：U1-14

### GENERAL-RATE-005：Agent 系统需要在哪些层做限流？

常见追问：

- 用户、租户、模型、工具、并发任务和 Token 应如何分别限流？
