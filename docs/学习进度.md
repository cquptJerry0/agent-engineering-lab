# Agent 核心知识学习进度

## 1. 文档定位

这份文档只记录学习状态和掌握证据，不解释知识内容。

知识定义、章节关系和第一轮要求以[学习总纲](学习总纲.md)为准。

较难英文术语的通俗解释统一放在学习总纲中，进度表只保留可搜索的知识点名称，避免重复释义造成两份内容不同步。

## 2. 状态说明

```text
未开始 → 已理解 → 已实验 → 已整合 → 已复核
```

状态升级必须提供知识卡片、代码、测试、Trace(完整执行轨迹)、失败分析、架构图或复测记录。“看完资料”不作为掌握证据。
