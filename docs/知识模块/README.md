# Agent 知识模块

## 1. 定位

这个目录承载 Agent 学习的知识正文。

[学习总纲](../学习总纲.md)负责规定完整知识边界，本目录负责把总纲中的稳定模块写成真正可以理解、复习和用于面试的内容。

```text
学习总纲：防止漏学
    ↓
理解版：建立推导式心智
    ↓
题目版：形成面试输出
    ↓
课程：通过互动和实验完成学习
    ↓
学习进度：记录掌握证据
```

## 2. 为什么采用理解版和题目版

只写理解资料容易出现“看懂了但说不出来”，只写题目答案容易出现“记住结论但接不住追问”。

同一个知识模块需要经过两次编译：

| 版本 | 主要问题 | 核心产物 |
|---|---|---|
| 理解版 | 这个机制为什么存在，怎样工作，怎样失败 | 推导链、ASCII 图、案例、协议、实验、边界 |
| 题目版 | 面试官怎样问，我怎样从判断答到证据 | 30 秒回答、3 分钟回答、追问链、反例、项目证据 |

题目版必须链接理解版，不能独立发明定义；理解版也要接受题目版的追问检验。

## 3. 与旧学习体系的复用关系

旧学习资料中最值得保留的不是 React 或网络本身，而是下面的内容生产结构：

```text
推导式理解
  +
完整知识脑图
  +
分类满分题解
  +
面试输出手册
```

Agent 仓库不机械复制四套正文，而是压缩为职责更清楚的结构：

| 旧结构 | 当前承接位置 |
|---|---|
| 推导式理解 | 每个模块的`理解版.md` |
| 完整知识脑图 | `学习总纲.md`全景图和理解版末尾知识图谱 |
| 分类满分题解 | 每个模块的`题目版.md` |
| 面试输出手册 | 题目版中的 30 秒、3 分钟和连续追问 |
| 训练 Prompt | 仓库`AGENTS.md`和课程模板 |

这样保留旧体系的心法，同时避免新增一批互相重复的文档。

## 4. 目录约定

每个稳定模块使用自然语言命名，不使用字母编码：

```text
docs/知识模块/
├── README.md
├── 理解版模板.md
├── 题目版模板.md
├── Agent执行循环/
│   ├── 理解版.md
│   └── 题目版.md
├── 上下文状态与记忆/
│   ├── 理解版.md
│   └── 题目版.md
└── ...
```

当前只建立结构和模板。正式学习某个模块时再创建正文，不提前生成空目录和空课件。

## 5. 内容生成顺序

一个模块按下面顺序完成：

1. 在学习总纲确认唯一主归属和完整知识边界。
2. 使用[理解版模板](理解版模板.md)写出推导链、机制、案例、失败和实验。
3. 用真实实验、官方协议、源码或 Trace 校正理解版。
4. 使用[题目版模板](题目版模板.md)生成面试答案和连续追问。
5. 通过课程进行互动学习和失败实验。
6. 将课程中暴露的新问题回写理解版或题目版。
7. 在学习进度中记录掌握证据。

一句话收束：总纲保证不漏，理解版保证真懂，题目版保证会说，课程和实验保证做过。
