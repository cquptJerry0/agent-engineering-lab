1. 开课准备

## 1. 开课准备

读取：

- 目标课程及相邻课程的完整合同。
- 目标面试题原文和追问。
- 对应知识正文。
- 已有课件和学习进度。
- 可用实验环境和文件权限。

先判断授课单元，不要直接复制课程目录。

开课总览：

```text
授课单元：
覆盖课程：
中心问题：
目标面试题原文：
题目关系：
答案骨架：
案例：
实验产物：
不展开内容：
授课模式：
```

## 2. 知识密度与动态合课

### 保持单课

单课能够独立形成下列闭环时保持不变：

```text
完整问题
  +
机制推导
  +
正常实验
  +
失败实验
  +
结构化面试回答
```

### 合并相邻课程

出现下列信号时，检查相邻课程是否应该合并：

- 单课正文主要是定义或接口名。
- 实验必须依赖下一课才能闭环。
- 多课的目标题属于同一条连续追问链。
- 多课使用同一个案例，但被课号机械切断。
- 单课没有足够内容支撑一个独立失败实验。

合并决策表：

| 检查项 | 合并条件 |
|---|---|
| 中心问题 | 可以用一句话统一 |
| 认知依赖 | 相邻且连续 |
| 案例 | 可以共享同一状态和输入 |
| 实验 | 可以逐层增加机制 |
| 面试题 | 可以形成连续追问 |
| 进度 | 原课程证据仍可独立映射 |

任一课程存在独立复杂机制、独立失败边界或显著认知负担时，不强行合并。

## 3. 连续引导授课

默认使用总分总。

### 总：开题

1. 展示真实问题。
2. 展示完整面试题原文。
3. 画题目关系图。
4. 给出答案骨架，但不提前倾倒完整答案。

### 分：问题章节

每章按下面的推导单元组织：

```text
问题
  ↓
直觉答案
  ↓
反例或失败
  ↓
具体数据与状态
  ↓
ASCII 图
  ↓
机制解释
  ↓
实验
  ↓
局部结论
  ↓
题目映射
```

思考点后直接继续，不等待学习者回复。

### 总：面试收束

逐题形成：

```text
一句话判断
30 秒回答
3 分钟回答
手画图
追问树
实验与 Trace 证据
边界
```

最后集中安排巩固题，不在讲授途中频繁打断。

## 4. 互动诊断授课

互动模式仍使用同一总分总结构，但每次只推进一个问题章节。

流程：

```text
给出具体问题
  ↓
等待学习者判断
  ↓
复述其当前心智
  ↓
指出成立部分与缺口
  ↓
用图、数据或实验推进
  ↓
再做一个迁移预测
```

用户答案基本正确时补边界并加速；答案混乱时缩小到一条调用链、一个 JSON 或一个状态变化。

## 5. 思考引导

思考引导的目标是制造认知冲突，不是制造停顿。

优先使用：

| 类型 | 示例 |
|---|---|
| 预测 | 工具返回 success 后，系统下一步一定结束吗？ |
| 反例 | Temperature=0 时，为什么仍可能稳定答错？ |
| 取舍 | 这个问题应该改 Prompt，还是增加外部验证？ |
| 排障 | 结论错误最先检查模型、上下文、工具还是停止条件？ |

每个思考问题必须在随后正文中被明确回答，并产生一个可复述的局部结论。

避免：

- 连续提出多个问题但不回答。
- 使用“你觉得呢”“懂了吗”制造假互动。
- 问题与后续机制无关。
- 只问定义和术语回忆。

## 6. 中断恢复

恢复时读取正式课件和状态，回答：

```text
当前授课单元覆盖哪些原课程？
已经讲完哪些问题章节？
哪些实验已有证据？
哪些面试题已经闭环？
下一步最小动作是什么？
```

连续引导模式恢复到最早未完成的问题章节；互动模式先用一个短问题复核前置心智。
