## 1. 掌握维度

| 维度 | 证明方式 |
|---|---|
| 定位 | 说明它解决的问题和所在系统层次 |
| 机制 | 不看资料推演关键输入、状态和输出 |
| 图 | 独立画出调用链、状态图或信任边界 |
| 实现 | 完成最小正常实验 |
| 排障 | 根据陌生失败证据定位根因 |
| 边界 | 说明不适用场景和替代方案 |
| 表达 | 完成 30 秒和 3 分钟回答 |
| 迁移 | 换框架、案例或题目后仍能识别机制 |

## 2. 完课门禁

使用三档结果：

```text
未通过
待复核
已通过
```

### 未通过

- 只能复述术语。
- 无法画图或推演状态。
- 只能跟着完成实验。
- 失败后依赖提示才能定位。

### 待复核

- 当场可以独立完成机制和实验。
- 仍缺少间隔复习或陌生案例迁移。
- 面试连续追问存在明显薄弱点。

### 已通过

- 正常和失败实验均有证据。
- 能分析一个未见过的变体。
- 能说清什么时候不用。
- 面试回答能落到代码、Trace、指标或产物。

## 3. 面试验收

每道主问题至少追三层：

1. 原理：最小机制、协议和状态。
2. 工程：失败、安全、性能和演进。
3. 项目：真实做法、证据和取舍。

验收时刻意改变问法。若只能识别题库原句，说明仍在背答案。

高质量回答结构：

```text
核心判断
  ↓
最小机制和图
  ↓
现实约束
  ↓
失败与取舍
  ↓
实践证据
```

## 4. 间隔复习

默认复习点：

- 下一节课开头：用一个短问题回忆前置心智。
- 本章结束：跨课 Trace 排障和随机抽题。
- 若学习周期较长：在约一周后重新画图或重做失败实验。

用户给出明确时间计划时，把复习写入具体日期；没有时间预算时，不伪造日程。

复习优先级：

```text
曾经答错
  ↓
实验失败
  ↓
只能背诵
  ↓
长时间未复核
  ↓
已经稳定迁移
```

## 5. 薄弱点修复

不要整课重讲。按暴露问题选择最小修复：

| 薄弱表现 | 修复方式 |
|---|---|
| 定义混淆 | 用相邻概念对比图 |
| 无法推演 | 改用具体数据和逐步状态 |
| 实验会做但不懂 | 先预测结果，再改一个变量 |
| 失败定位混乱 | 使用故障层次树和逐条证据 |
| 面试表达松散 | 先压缩成一句话，再扩展三分钟 |
| 只会固定案例 | 换领域或框架做迁移题 |

修复后必须重新验收原薄弱点，不能只补讲解。
