## 4. 文档职责

```markdown
| 文档 | 唯一回答的问题 | 权威内容 | 不包含 |
|---|---|---|---|
| README | 从哪里开始 | 导航 | 知识正文 |
| 总纲 | 完整体系是什么 | 唯一定义 | 进度日志 |
```

配套引用关系：

```text
README
  ├── 总纲
  ├── 方法
  ├── 进度
  ├── 资料
  └── 前沿
```

## 5. 章节样稿

```markdown
## 章节名称

### 章节目标

### 核心心智

### 核心知识点

- 概念：它解决的问题、最小机制和边界。

### 容易混淆的概念

### 常见失败

### 最小实验或验证

### 第一轮掌握要求

### 与其他章节的关系
```

不要求机械保留所有小标题，但内容职责不能缺失。
